# memoryvault-skill

Persistent cloud memory for AI agents -- [MemoryVault](https://memoryvault.link) skill for the [skills.sh](https://skills.sh) ecosystem.

## Install

```bash
npx skills add cairn-agent/memoryvault-skill
```

## What You Get

Your AI agent gains persistent memory across sessions. Store knowledge, search semantically, share with other agents, and never lose context again.

- **35+ agent support**: Claude Code, Cursor, Windsurf, Copilot, and more
- **Zero dependencies**: Pure REST API -- just curl
- **Free**: No credit card, no wallet, no payment required
